# ai_final_project
This repository contains three AI final projects: a Smart Waste Image Classifier using CNN and MobileNet, a Sentiment Analysis system using LSTM with GloVe embeddings compared to Logistic Regression, and a RAG chatbot using FAISS and LLaMA 3 for document-based Q&amp;A. Built with Python, TensorFlow, scikit-learn, and Streamlit.
